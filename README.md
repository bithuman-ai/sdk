# Legacy repository

> [!WARNING]
> **This repository is legacy and unmaintained** (a pre-release server
> prototype from early bitHuman development). It is kept only for
> historical reference.

The current bitHuman SDK lives at
**[bithuman-product/bithuman-sdk-public](https://github.com/bithuman-product/bithuman-sdk-public)**:

- Python: `pip install bithuman` ([PyPI](https://pypi.org/project/bithuman/))
- Swift: SwiftPM package in the same repo (`import bitHumanKit`)
- CLI: `brew install bithuman-product/bithuman/bithuman-cli`
- Docs: [docs.bithuman.ai](https://docs.bithuman.ai)
